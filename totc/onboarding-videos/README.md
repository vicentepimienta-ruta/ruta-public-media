# TOtC Onboarding Wizard Videos

Explainer videos for the Think Outside the Chat™ learner onboarding wizard, one per wizard step (W1–W5), each in English and Spanish.

Structure: `w{1..5}/{en,es}/` — each language folder holds `onboarding-w<N>-<name>-<lang>.mp4` (H.264 1080p), `.vtt` captions, `-poster.png`, `-script.txt` and a `-qa-<date>.md` report. Folders appear when their assets are Director-approved; `manifest.json` is the single source of truth for what exists, its public URL and its approval status. Unapproved work stays out of `main` (staged on `staging-*` branches, never served at media.rutamethod.com).

Production rule: one calm narrator, voice only, no music, no effects. Brand Style Manual v2.1. Human-Led. AI-Assisted.
